WHAT DAY 1 DOES
1. Fancy responsive MY GYM login/register interface.
2. Firebase Email/Password account creation.
3. Firebase login/logout.
4. Creates each user's basic profile in Cloud Firestore.
5. Shows a simple signed-in dashboard.
6. Ready to host with GitHub Pages.

IMPORTANT
- You must replace the placeholder values in firebase-config.js with your Web App config from Firebase.
- Paste firestore.rules into Firebase Console > Firestore Database > Rules > Publish.
- Do NOT upload service-account private keys or admin credentials to GitHub.
